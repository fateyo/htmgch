我用来运营博客和直播的工具

原文标题：The tools I use to run a blog and stream

独立游戏营销综合

三句话概括

文章是一份作者用于经营博客、视频、线上演讲和 Steam 页面拆解内容的设备清单。它按三类使用场景推荐工具：业余时间做游戏的开发者、需要 Zoom 演讲的人，以及想做直播或录制视频的人。重点不在高端炫技，而是说明哪些设备真正提高了安静工作、录音、灯光、演示和视频制作效率。

浓缩短文

这篇文章本质上是一份面向游戏开发者和内容创作者的办公室设备指南。作者展示了自己用于每周更新营销博客、录制视频和做线上演讲的真实办公环境，并在 Cyber Monday 和假日季背景下，拆解哪些工具值得购买。他也说明文中包含联盟链接，但推荐的都是自己日常实际使用的设备。

文章把推荐对象分成三类：只能在晚上和周末做游戏的人、需要在 Zoom 或会议上演讲的人，以及想录制或直播视频的人。对于仍有全职工作、还在上学、只能挤时间开发游戏的人，作者首先推荐 Logitech K380 多设备蓝牙键盘。理由不是性能，而是安静。很多人喜欢机械键盘，但如果同住者已经睡觉，敲击声会成为问题。K380 便宜且非常安静，适合小公寓或共享居住空间。

作者还推荐 A4 描图纸，用于游戏设计草图。他在设计 1 Screen Platformer 时，曾把每个陷阱都手绘在纸上。他的父亲是景观设计师，教过他建筑师如何用描图纸叠加草图和布局，因此他认为这仍然是很有价值的设计工具。另一个偏实用的推荐是带 12 个插座和 4 个 USB 口的 ALESTOR 防浪涌插排。作者不想再钻到桌下找插头，于是在办公室各处安装多个插排，并用 3M Command 胶条贴到墙上，再插入加长的 Apple Lightning 和 USB 3 线，确保任何设备都能在一步之内接上电。

在基础录音方面，作者推荐 Blue Snowball iCE USB 麦克风。他承认市面上有更好的麦克风，但从易用性、声音和价格综合来看，这款是最均衡的选择，他已经用了很多年。为了让长期开发时的环境更舒服，他还推荐复古 Edison 灯泡和吊线。这些灯可以调光，既能改善办公室氛围，也能让空间看起来像带有蒸汽朋克气质的新闻编辑室。对于游戏开发、录音和视频产生的大量数据，他使用 WD 6TB My Book 桌面外置硬盘作为本地存储，因为这些素材很快会填满 SSD。

面向线上或线下演讲者，作者首先推荐无线翻页笔。好的演讲者不应该被笔记本电脑束缚，哪怕是在 Zoom 上演示，敲空格键或方向键也会被观众听到明显的键盘声。他使用 DinoFire Wireless Presenter，在各种演讲中都拿在手里；附带的激光笔也能用于现场指示。灯光方面，他推荐 LED 环形灯。正面摆放会让人看起来更好，但会在眼睛里形成明显的光环，如果不喜欢这种效果，可以把灯放在人物与摄像机成 45 度的位置，仍然能得到专业观感。

如果经常做专业演讲，作者建议升级到 XLR 麦克风系统。相比前面提到的 USB Snowball，三针 XLR 设备声音更厚、更专业，但需要前置放大器把 XLR 转成 USB，还需要 XLR 线和支持 XLR 接口的麦克风。作者在 GameMarketingIdeas.com 视频中使用的金色麦克风就是这套系统的一部分。为了减少房间回声，他还购买了两套 50 片装吸音海绵板，贴在办公室硬表面上，避免录音听起来像在回声很重的球场里。

面向视频录制和直播，作者投入更高。他不喜欢普通网络摄像头，因为会把他的肤色拍成奇怪的粉红色，于是购买了 Sony Alpha A6100 微单相机，用于 4K 视频流。他做了大量研究后选择这台相机，并指出许多专业 Twitch 主播也使用它。为了获得近距离拍摄和足够宽的绿幕画面，他搭配了 16mm 镜头；同时，为了长时间直播不耗尽电池，还使用了电源适配器。

4K 视频流的链路比普通摄像头复杂：画面从 Sony 相机出来，经 HDMI 线进入 Elgato 4K 转 USB 采集卡，再进入 PC、OBS，最后推到 Twitch 或 Zoom 等平台。因此 HDMI 线和 Elgato 4K 适配器是关键设备。为了营造主播常见的梦幻粉蓝背景，作者使用 Pixel G1s RGB 便携视频灯，可以调成任意 RGB 色彩；还会把彩色透明胶片，也就是 gels，盖在高亮裸灯上，让白光变成彩色光斑。

最后是绿幕。作者在 GameMarketingIdeas.com 做 Steam Page Teardown 时，会站在绿幕前，OBS 通过色键抠像把背景替换成浏览器画面。他购买的是 Chromakey 绿色无缝棉布背景，并用背景架夹住。设备并不昂贵，但足以完成任务。整篇文章的价值在于，它不是抽象谈“做内容要专业”，而是把安静输入、素材存储、演讲控制、声音质量、房间吸音、摄像机、采集卡、灯光和绿幕这些具体环节拆开，让开发者根据自己的内容生产需求逐步搭建工作环境。
