如果 Microsoft 收购 Discord 该怎么办：别先恐慌

原文标题：What to do if Microsoft buys Discord (Step 1 don’t panic)

打开原文

邮件列表与私域 定价、折扣与收入 社媒传播

三句话概括

这篇文章写于 2021 年 3 月，当时有消息称 Microsoft 正在谈判以约 100 亿美元收购 Discord。作者认为独立游戏开发者不必恐慌，因为 Microsoft 很可能会改善 Discord 的基础设施、通知和稳定性，即使最坏情况发生，也可以靠邮件列表保住与玩家的直接联系。文章核心观点是：Discord 很重要，但社区触达不能押注在任何一家大公司身上。

浓缩短文

2021 年 3 月，有消息泄露称 Microsoft 正在谈判以约 100 亿美元收购 Discord。对游戏开发者来说，Discord 是非常重要的中段漏斗（mid-funnel）营销渠道。它适合触达那些已经听说过游戏、但还没有下定决心购买的玩家，并给他们最后一点推动。听到这个平台可能落入新东家手里，开发者自然会紧张，但作者认为这未必是坏事。

作者的简短判断是：Microsoft 很可能会让 Discord 变得更好，比如补上邮件通知、提升在线稳定性。Discord 本身并没有赚到特别多钱，但 Microsoft 也许并不在乎它单独盈利，因为 Discord 可以帮助 Xbox、Game Pass 等其他业务赚钱。即使 Microsoft 最终搞砸了 Discord，开发者也不应该陷入绝境，因为他们本来就应该持续建设邮件列表，而不是把整个社区关系交给一家大公司。

文章用产品市场匹配（product-market fit）解释为什么大公司会收购小公司。小公司很难随机做出真正被用户热爱的产品，Discord 就是那种从大量失败创业公司中跑出来的幸运成功者。很多年轻用户真心喜欢 Discord，进入门槛也极低。玩家只需点一下就能加入服务器，围绕 Discord 的机器人生态又能补足很多产品短板。作者自己的经历也说明了这种自然吸引力：他最早并不是主动想建 Discord，而是因为有速通玩家为他的游戏 1 Screen Platformer 建了非官方服务器，他才不得不建立官方服务器；后来 HowToMarketAGame 的讨论又在游戏服务器里变得太多，他才另建了营销社区。

Discord 最大的优势是容易加入，最大的问题则是互动效率还不够高。作者提到，如果在 Discord 用 @everyone 发链接，点击率大约只有邮件营销的一半左右。他认为 Microsoft 如果接手，很可能会安排互动增长专家研究如何让用户更频繁打开 Discord、阅读消息、点击链接。最直接的做法就是接入邮件通知。Discord 当时几乎不会针对服务器动态发送邮件，这在作者看来很奇怪。服务器管理员 @everyone 时，Discord 完全可以给成员发送对应邮件，也可以每周汇总用户加入的所有服务器里最热门的评论、反应最多的消息。

作者承认很多人讨厌邮件，但邮件确实有效。Facebook、Twitter/X、Slack 等平台默认发送邮件提醒，就是因为没有什么渠道比邮件更能拉回用户注意力。如果游戏开发者准备在 Discord 发“我们的游戏已经上线，去 Steam 购买”的消息，Discord 若能同时发邮件通知，就会带来更多点击和更多销售。

Discord 的商业化也不强。文章引用数据称，Discord 2020 年收入约 1.3 亿美元，活跃用户 1.4 亿；相比之下，Twitter/X 有 3.53 亿活跃用户，收入 37 亿美元。也就是说，Twitter/X 的用户规模约是 Discord 的两倍多一点，收入却是 Discord 的 28 倍。Discord 曾尝试卖游戏，但因为没人买而放弃；团队也一直不愿投放广告，所以收入主要来自每年 99 美元的 Nitro 订阅。对 Microsoft 来说，这反而不是大问题。Discord 可以作为亏损引流业务存在，只要它能提升 Xbox 或 Game Pass 的价值。例如 Microsoft 可以把 Nitro 权益打包进 Xbox Game Pass，以提高订阅吸引力，甚至为 Game Pass 涨价提供理由。

作者还认为，Microsoft 可能会改善 Discord 的稳定性。Discord 经常宕机，而 Microsoft 有动力展示 Azure 云技术，把 Discord 从 Google Cloud 迁移出来并提高可用性。Microsoft 也可能让服务器更容易被发现，例如在 Microsoft 游戏商店页面加入 Discord 链接。Discord 在某种意义上取代了旧式游戏论坛，但公共讨论记录的可搜索性很差，不利于游戏历史保存。作者希望 Microsoft 能利用搜索技术改善 Discord 的可发现性和可检索性。

当然，文章也讨论了最坏情况。有人可能担心 Microsoft 会像当年 Skype 那样毁掉 Discord。作者认为现在的 Microsoft 领导层已经不同，Minecraft 和 GitHub 被收购后仍然运转良好，不是那个把 Skype 做坏的 Microsoft。有人还可能担心 Discord 变得封闭，不允许发 Steam 链接。作者认为这不太可能，因为 Microsoft 已经有足够多内容审核问题，不会把精力放在禁止开发者链接竞争平台上。如果 Microsoft 在 Discord 投放广告，作者反而认为这可能给游戏营销带来一个新广告平台。

真正的风险不是 Microsoft 一定会毁掉 Discord，而是开发者不该把社区押在任何单一公司上。作者反复强调，不要把自己的社区托付给大公司。平台规则、推荐机制、通知方式、商业模式都可能变化，社区可能因为一次产品决策而蒸发。因此，开发者应该在 Discord、Twitter/X、Steam 等渠道之外持续建设邮件列表。邮件是互联网基础技术，不由单一公司拥有。只要你有玩家邮箱和同意订阅的许可，没有哪家公司能轻易切断你与玩家的直接联系。

所以，如果开发者真的担心 Microsoft 会毁掉 Discord，最实际的应对不是恐慌，而是现在就开始收集邮件列表。Discord 仍然可以用，而且很可能会变得更强；但邮件列表才是独立游戏长期营销里更稳固的底层资产。
