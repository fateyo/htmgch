为什么每个 Dream-Build-Play 获奖者都是带草地的 2D 平台游戏？

原文标题：Why is every Dream-Build-Play winner a 2D platformer with grass?

打开原文

课程、书籍与服务

三句话概括

作者观察 Microsoft Dream-Build-Play 历届大奖得主，发现几乎都偏向漂亮、可爱、无冒犯性的 2D 平台游戏，常见蓝天、绿草、卡通画面和顺滑动画。文章认为这与比赛希望向公众展示 XNA/XBLIG 社区“美好、易接受”的形象有关，而不是奖励最激进或最颠覆的设计。作者最后半开玩笑地建议，想拿大赢家就少做抽象、暴力、僵尸和枪械，多做草地、蓝天、可爱动物和漂亮动画。

浓缩短文

2012 年，Microsoft 宣布 Dream-Build-Play 2012 开放报名。Dream-Build-Play 是展示使用 XNA 工具制作的年度优秀游戏的竞赛，当时已经举办到第六届。作者准备让自己的 City Tuesday 参赛，因为截止日期近在眼前，可以逼迫他把游戏完成。与此同时，他回顾了过去历届大奖得主，发现这些游戏之间有一种近乎诡异的相似性。

作者列出 2007 到 2011 年的大奖得主：2007 年是 The Dishwasher，2008 年是 CarnyVale，2009 年是 Dust: An Elysian Tail，2010 年是 Lumi，2011 年是 Blocks That Matter。他观察到，所有大奖得主都是 2D 平台游戏。五款里有四款拥有可爱的主角，甚至有人可能会把 The Dishwasher 的 James Silva 作品也看作某种“可爱”的异类。五款里有四款采用高饱和度卡通画面，几乎没有血腥元素；三款有特别葱郁的环境，包括绿草和蓝天；而真正带有枪械元素的只有 The Dishwasher 这个例外。

作者承认，小型独立开发者在一两年内能完成的类型本来就有限，但 XBLIG 平台并不缺少双摇杆射击、SHMUP、RPG 和僵尸游戏。问题是，这些类型从未出现在大奖得主里。甚至 Dream-Build-Play 的第二名和第三名，类型多样性都比大奖更明显。这让作者追问，为什么 Microsoft 年复一年地选择本质上如此相似的游戏。

他的解释是，Dream-Build-Play 从名字上就带有“实现梦想”的意味，它要向公众展示这个开发者社区做出的游戏多么美好、多么令人向往。它不是一个用来展示粗糙但激进、挑战传统游戏概念作品的场合，也不是鼓励评委重新思考“游戏是什么”的竞赛。获奖游戏往往在静态截图里就很漂亮，手感好，动画顺滑，不冒犯人，并且能让最广泛的受众觉得愉快。作者把它比作游戏制作里的“轻音乐”。

这并不是说作者看不起这些获奖游戏。相反，他承认每一款都有很高的完成度，质量达到他自己的作品只能梦想接近的水平。他真正厌倦的是同一种类型、同一种审美连续获胜。Dream-Build-Play 似乎不断奖励那些最容易被大众认为“好看、舒服、可爱”的游戏。

为了说明这一点，作者引用了 This American Life 中一个关于艺术市场研究的片段。两位艺术家聘请营销研究公司调查人们心目中美丽绘画的样子，项目负责人 Alex Melamid 发现，最能让大众满意的画通常是带有蓝天、野生动物、水和山的风景画。作者认为，这与 Dream-Build-Play 获奖游戏的蓝天、绿草、可爱角色和明亮画面非常相似：它们都是经由最大公约数审美筛选出来的安全答案。

作者曾询问 Microsoft 社区经理，Dream-Build-Play 的评委到底是谁，但得到的回答是保密。他原本想知道评审是否邀请了知名游戏评论人，例如 Kotaku 主编 Stephen Totilo。作者提到，Totilo 在 2007 年，也就是 Portal 发售的同一年，把 Desktop Tower Defense 选为自己的年度游戏，这说明某些评论人可能会更愿意奖励非传统作品。作者猜测，真正投票的可能是与 XBLIG 社区有利益关系的各部门项目负责人，比如 XNA 项目经理、Xbox Live 市场负责人，或 Larry “Major Nelson” Hryb。

文章最后的判断带有调侃意味：如果开发者希望赢得 Dream-Build-Play 大奖，就不要指望靠重新定义游戏、抽象艺术、反讽式暴力剥削片风格、血腥僵尸或子弹横飞的玩法取胜。更稳妥的方向是绿草、蓝天、可爱动物和漂亮动画。作者并不是否认这些元素能做出好游戏，而是在提醒开发者，比赛奖励的并不只是创意本身，还包括作品能否在公开展示、市场传播和大众审美中显得安全、漂亮、令人愉快。
