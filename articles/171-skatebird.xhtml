Independent Games Summit：分层打造《SkateBIRD》品牌

原文标题：Independent Games Summit: Building The ‘SkateBIRD’ Brand In Layers

打开原文

发售节奏与窗口 Steam Next Fest 与节日活动 愿望单增长与质量 社媒传播 定价、折扣与收入

三句话概括

文章整理了 Megan Fox 在 Independent Games Summit 上关于《SkateBIRD》的复盘，重点是如何从一开始就按“可营销性”构建游戏品牌。团队先做出看起来足够完整、好传播的垂直切片，再通过 Kickstarter、平台合作、展会和线上节日逐步放大声量。《SkateBIRD》最终依靠 Game Pass 支持在首日盈利，收入来源中 Xbox 占 50%，Steam 占 13.4%，Switch 占 17.5%。

浓缩短文

这篇文章记录的是 Megan Fox 关于《SkateBIRD》的演讲。《SkateBIRD》最初接近一个单人项目，后来根据社区反应逐渐扩大规模。演讲一半是项目复盘，一半是关于如何在游戏不断膨胀的情况下同步安排融资、营销场合和发行路径的经验总结。Megan Fox 之前做过 2012 年移动游戏《Jones on Fire》、2015 年通过 Kickstarter 推动的 Steam 游戏《Hot Tin Roof》，以及由 Indie Fund 支持的《Spartan Fist》。作者特别提醒，《Spartan Fist》的回收条款让团队没有继续更新它的动力，也没能让它反过来帮助公司，这说明发行或投资合同里的 recoup 机制必须仔细看。

《SkateBIRD》的方法是从市场性开始。团队选择了一个当时相对被放弃的类型空间，也就是《Tony Hawk》式滑板游戏，又用“会滑板的小鸟”这种天然适合 GIF 传播的概念，做了一个很小的垂直切片。Megan 的核心建议是，在正式公布游戏之前，它应该已经看起来很好，甚至像明天就能发售。她并不是建议用 CG 做假预告，而是要在引擎内把核心资产做得足够好，在真实游戏的基础上“包装”出清晰吸引力。玩家、媒体和平台会在发售时继续使用你早期发布的截图，所以一开始放出去的画面不能太糟。

所谓“营销优先”，不是忽视玩法，而是不要从一堆灰盒开始对外展示。团队应该尽早做出最低限度可接受的美术、Logo 和颜色方案。Logo 值得花钱，颜色方案要早定，因为这些都会影响玩家是否愿意分享。漂亮的画面更容易在社交平台上传播，也更容易获得平台和影响者的兴趣。Megan 提到这个营销优先策略来自 Tanya X Short。到正式发售时，《SkateBIRD》的营销素材已经进化，能展示更多内容和变化；但在初次公布时，素材可以更集中，只要核心乐趣和动作表现足够清楚。

《SkateBIRD》的公布并不是和 Kickstarter 同时进行。Megan 认为，如果一边说“看，这个游戏像已经完成了”，一边又说“我们需要钱”，信息会分裂。所以团队先让游戏以一个完整、有趣、看起来能很快发售的形象出现，之后再推进 Kickstarter。公布当天热度很高，但 Megan 当时在度假，网络受限，这也带来一个教训：重要公布最好安排在团队能及时响应的时间。

融资方面，发行商一开始拒绝了《SkateBIRD》，但平台表现出兴趣，项目后来转向 Kickstarter。团队通过 Kinda Funny 的 showcase 获得曝光，并在 E3 2019 期间配合 Kickstarter 启动。项目预算为 21.5 万美元，Kickstarter 加上平台资金已经足够。其他重要助推包括 Geoff Keighley 看到相关内容后邀请他们参加 The Game Awards 或相关节日活动，带来了巨大的愿望单增长；Nintendo 也因此联系了他们。

高热度也有风险。部分玩家把《SkateBIRD》想象成《Skate 4》，但它并不是那类游戏。《SkateXL》偏模拟，而《SkateBIRD》瞄准的不是同一批玩家。Demo 中存在一些粗糙感，团队也没有把规模继续扩大到彻底解决所有手感问题，而是在可承受范围内折中。疫情又改变了营销计划。线上游戏节开始变多，扭曲了愿望单数字，也改变了 PR 节奏。2020 年团队加入 Story mode，并在疫情期间主要打磨故事模式。每个线上节日都变成一次 PR 节点，团队需要不断拿出可宣布的内容。

项目后来延期，团队围绕日期变更做了一次 PR 节点，并且把新日期往后推得比预计需要的更远，以容纳潜在问题。这个选择被作者认为很聪明。他们还做了一个可爱的延期预告片，观众反应不错。游戏最终在 9 月 16 日发售，但那段时间新游戏很多，竞争激烈。发售后，《SkateBIRD》获得 85% 好评，Game Pass 的支持让它首日就已经盈利。最终数字显示，Xbox 占 50%，Steam 占 13.4%，Switch 占 17.5%，其他平台占 19.7%。文章还指出，愿望单转化并没有外界常说得那么高，但虚拟节日确实帮了很大忙，因为成本低、曝光节点多。

在社交传播上，《SkateBIRD》主要从 Twitter/X 起势，因为团队本来就活跃在那里，记者也更常使用 Twitter/X，而且玩过《Tony Hawk》的稍年长受众也更容易在那里被触达。团队与 Stride PR 合作，把多人模式、合作伙伴、秘密角色等信息安排成不同新闻节点，让媒体有东西可写。文章最后的结论很实际：可爱滑板鸟本身就是一个强卖点，但它能转化成商业结果，是因为团队从 Logo、画面、垂直切片、Kickstarter、平台资金、节日节点到 PR 节奏都在一层层搭建品牌，而不是等游戏做完才开始想怎么卖。
