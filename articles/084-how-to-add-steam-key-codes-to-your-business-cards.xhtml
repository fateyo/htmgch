如何把 Steam Key 码加到你的名片上

原文标题：How to add Steam Key codes to your business cards

打开原文

Steam 平台与商店机制 数据基准与行业观察 发售节奏与窗口

三句话概括

文章介绍了如何把唯一的 Steam Key 印在名片背面，用于展会销售、赠送或向媒体、主播、发行商展示游戏。流程包括从 Steamworks 下载 Key、用表格制作 CSV、在 Photoshop 中用变量文本批量生成图片，再通过 moo.com 印刷多款不同背面的名片。作者还提醒 Key 字号要大、避免黑底小字，并注意安全裁切区域。

浓缩短文

这篇文章是一份非常实用的展会物料教程，目标是在 GDC 或其他线下游戏展会上，把每一张名片都做成一份可兑换游戏的 Steam Key。这样拿到名片的人不仅获得联系方式，还能直接解锁一份游戏。作者认为这比把 Key 打在小贴纸上再手工贴到名片背面更专业，因为 Key 可以直接印在卡片上，并与名片整体字体、颜色和视觉风格统一。

这样做有两个用途。一个用途是现场销售。开发者如果在展位上，可以把自己的旧作或已发布游戏以实体卡片形式卖给路过玩家，对方付现金，你给一张印着 Steam Key 的名片。Steam 允许开发者免费申请 Key 并收费出售，不过用 Key 激活游戏后留下的评测不会计入 Steam 商店页的评测总数，所以不能靠这种方法快速凑够 10 条有效评测。作者还半开玩笑地说，经济拮据的独立开发者甚至可以在酒吧里用“请我一杯啤酒，我送你一份游戏”的方式交换。另一个用途是直接赠送。对媒体、影响者、发行商或自己敬佩的开发者说“你好，我是 Chris，这是一份我的游戏”，会比普通名片更容易被保留，也更有记忆点。

前提条件并不复杂。你需要有一款已经上传到 Steam 的游戏，需要能使用 Photoshop，还需要一个支持同一批名片印不同背面设计的印刷服务。作者使用 moo.com，因为质量稳定，并且支持 unique cards。需要注意的是，moo.com 一次印刷中默认只能有 50 种不同的卡片背面，超过后会加钱，但额外费用不算太高。

第一步是在 Steamworks 里下载 Steam Key。登录 Steamworks 后，点击 Request Steam Product Keys。如果要赠送已经发售的游戏，选择 Default Release Key 下的 Giveaway Keys；Steam 会提醒不要一次申请太多，作者通常一次只申请 100 到 200 个。如果游戏还没发售，则使用 Release State Override。之后导出 CSV，就会得到一组类似 2GAZQ-R8FTM-A8YJW 格式的 Key。文章中的这个例子是作者随手敲出来的随机字符串，并非真实可用 Key。

第二步是用 Google Docs 或 Microsoft Excel 制作给 Photoshop 使用的 CSV。新建一个表格，创建一列，列名写成 KEY_CODES，然后把所有 Steam Key 粘贴到这一列下面，最后导出为 .CSV 文件。这个表头非常重要，因为后面 Photoshop 的变量文本会用它来匹配数据。

第三步是在 Photoshop 中设计名片背面。一张常见名片的尺寸是 1038 x 696 像素，300ppi。如果不擅长设计，作者建议先用 Canva 搜索名片模板，很多模板免费。设计图中需要创建一个文本图层，放置将被替换成 Steam Key 的占位文字，例如 ####-####-####-####，并提前设好最终想要的字体、字号和颜色。

接下来要把这个文本图层设置为变量。确保 Photoshop 当前使用移动工具，并且没有选中具体对象，然后进入 Image > Variables > Define。选择刚才用于显示 Key 的文本图层，勾选 Text Replacement，并输入 KEY_CODES。这个名字必须和 CSV 第一行的表头完全一致。确认后，再进入 Image > Variables > Data Set，点击 Import，选择刚才导出的 .csv 文件。导入成功后，可以用对话框里的箭头在不同 Key 之间切换。再执行 Image > Apply Data Set，占位文字就会变成 CSV 中的一条 Key。此时画面上只会看到其中一条数据，这是正常的，批量生成会在下一步完成。

第四步是批量导出 PSD。点击 File > Export > Data Sets as Files，选择输出文件夹，文件名设置保持默认即可。Photoshop 这一步只能导出 .psd，不能直接生成 .jpg。导出完成后，输出文件夹里应该会有大量 PSD 文件，每个文件都对应一条不同的 Steam Key。作者建议打开其中几个检查，确认不同 Key 已经正确应用到不同文件中。

第五步是把 PSD 批量转换成 JPG，因为名片印刷网站需要图片格式。进入 File > Scripts > Image Processor，在第一项选择刚才存放 PSD 的文件夹，在第二项选择新的输出文件夹，第三项选择输出文件类型为 JPG，然后运行。Photoshop 会遍历文件夹中所有 PSD，并生成对应 JPG。到这一步，你就拥有了一整个文件夹的名片背面图片，每张图都有唯一 Steam Key。

最后一步是在 moo.com 上印刷。选择 Business Cards > Original Business Cards，作者强烈建议使用标准尺寸，不要做方形或迷你名片，因为这类异形卡片很难和别人收到的大量普通名片一起收纳。纸张和圆角可按喜好选择，作者偏好哑光，认为亮光看起来廉价。然后选择 Upload a full design，在背面卡片区域点击 Add a new design，再批量上传所有带 Key 的 JPG。名片正面只需要上传一张统一设计，因为所有卡片正面相同。完成后加入购物车即可。

作者最后给了几个印刷经验。Steam Key 的字号要比你想象中更大，因为名片很小，读起来容易吃力。不要做黑底白字或黑底彩字，即使用好打印机，油墨也可能轻微扩散，导致文字难读；而且深色名片不方便别人写备注，例如“展会上见过，很有意思，值得联系”。还要特别注意安全裁切区域，名片实际裁切会有轻微误差，如果 Key 的第一位数字被切掉，这张卡就失去意义了。
